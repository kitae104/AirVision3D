# 요구사항 정의서 (구현 현황 포함)

원 과제("AI 영상인식 기반 3차원 미세먼지정보 통합시스템")를 학생 캡스톤 MVP로 축소한 요구사항.
상태: ✅ 구현·검증 / 🔶 구현(육안 확인 대기) / ⏸ 보류 / ⬜ 선택(후순위)

## 1. 사용자

| 역할 | 권한 | 상태 |
|---|---|---|
| 일반 사용자(USER) | 현재 상태·시계열·비교 조회, 지도 탐색 | ✅ |
| 관리자(ADMIN) | + 데이터 등록·삭제, AI 예측·보간 실행, 성능 확인 | ✅ |

## 2. 기능 요구사항

### 데이터 관리
| 요구 | 상태 |
|---|---|
| 관측소·관측값(시각/좌표/환경값/PM2.5) 등록·조회·수정·삭제 | ✅ |
| 샘플 데이터 자동 생성 (관측 시드 + 합성 이미지 생성기) | ✅ |
| CSV 일괄 업로드 | ⏸ 실측 데이터 확보 시 (스키마 정의됨) |
| 이미지 파일 관리(images 테이블 연동 업로드) | ⬜ 예측 시 직접 업로드로 대체 중 |

### 이미지 전처리
| 요구 | 상태 |
|---|---|
| 리사이즈·정규화 | ✅ |
| 설정 기반 ROI (x,y,w,h) | ✅ |

| MAD 기반 이상치 확인·보정 | ✅ |
