1이 도구는 무엇인가요?

AirVision 3D는 대기 사진과 환경 정보(기온·습도·풍속)를 AI에 입력해 초미세먼지(PM2.5) 농도를 예측하고, 그 결과를 3차원 지도 위에 표시하는 시스템입니다. 다음 3가지 값을 한 화면에서 비교할 수 있습니다.

값 종류설명지도 마커 색
관측값관측소(센서)에서 실제로 측정한 PM2.5파랑
AI 예측값대기 이미지 + 환경데이터로 AI가 예측한 PM2.5주황
보간값관측소가 없는 지점을 주변 관측소로부터 거리 기반(IDW) 추정한 PM2.5보라

PM2.5 등급 색상 (모든 화면 공통)

등급PM2.5 범위 (㎍/㎥)색
좋음0 ~ 15파랑
보통15 초과 ~ 35초록
나쁨35 초과 ~ 75주황
매우나쁨75 초과빨강

2시작 전 준비물

내 컴퓨터에 아래 프로그램이 설치되어 있어야 합니다. 설치 여부는 명령 프롬프트(PowerShell)에서 버전 명령으로 확인할 수 있습니다.

프로그램버전확인 명령
Java21java -version
Node.js20 이상node -v
Python3.11python --version
Git최신git --version

그리고 접속 가능한 PostgreSQL 16 + PostGIS 데이터베이스가 필요합니다 (원격 서버 또는 로컬 설치). 프로젝트 관리자에게 접속 정보(주소·포트·DB명·계정·비밀번호)를 받아 두세요.

이 프로젝트는 Docker를 사용하지 않습니다. 모든 서비스는 내 컴퓨터에서 직접 실행되고, DB만 원격에 있습니다.

3최초 1회 설치

  1. 소스 코드 받기 — PowerShell을 열고 원하는 폴더에서: 
    git clone <저장소 주소> AirVision3D
cd AirVision3D
  2. 환경설정 파일 만들기 — 예시 파일을 복사해서 .env 파일을 만듭니다. 
    Copy-Item .env.example .env
  3. DB 접속 정보 입력 — 메모장 등으로 .env 파일을 열고 아래 항목을 채웁니다. 
    POSTGRES_HOST=<DB 서버 주소>
POSTGRES_PORT=<포트>
POSTGRES_DB=airvision
POSTGRES_USER=<계정>
POSTGRES_PASSWORD=<비밀번호>
    .env에는 비밀번호가 들어 있으므로 절대 Git에 커밋하거나 다른 사람에게 공유하지 마세요. (저장소의 .gitignore가 기본적으로 막아 줍니다)
  4. 끝! — 테이블 생성과 샘플 데이터 입력은 서버가 처음 켜질 때 자동으로 수행됩니다(Flyway). 라이브러리 설치도 첫 실행 때 자동으로 진행됩니다.

4실행하고 종료하기

한 번에 실행 (권장)

프로젝트 폴더에서 PowerShell로 아래 한 줄을 실행하면 백엔드·AI 서비스·프론트엔드가 각각 별도 창으로 켜집니다.

.\run.ps1

최초 실행은 라이브러리 자동 설치 때문에 몇 분 걸릴 수 있습니다. 3개 서비스가 모두 준비되면 완료 메시지가 표시됩니다.

"이 시스템에서 스크립트를 실행할 수 없으므로..." 오류가 나오면 이렇게 실행하세요:
powershell -ExecutionPolicy Bypass -File .\run.ps1

정상 실행 확인

서비스확인 주소정상일 때
웹 화면 (Frontend)http://localhost:5173로그인 화면 표시
백엔드 (Backend)http://localhost:8080/api/health"success": true 응답
AI 서비스http://localhost:8000/health"success": true 응답

종료

.\run.ps1 -Stop

또는 열려 있는 각 서비스 창을 직접 닫아도 됩니다.

전체 자동 점검 (선택)

세 서비스가 모두 켜진 상태에서 33개 항목을 자동으로 검사할 수 있습니다. 시연 전 점검용으로 유용합니다.

powershell -ExecutionPolicy Bypass -File .\scripts\integration-test.ps1

5로그인과 계정

브라우저에서 http://localhost:5173 에 접속하면 로그인 화면이 나옵니다. 기본 계정은 서버 최초 기동 시 자동으로 만들어집니다.

아이디비밀번호(기본값)역할할 수 있는 일
adminadmin1234!관리자조회 + 데이터 등록·삭제, AI 예측 실행, IDW 보간 실행
useruser1234!일반 사용자조회만 가능 (대시보드·3D 지도·관측 데이터·모델 성능)

로그인하면 왼쪽에 메뉴(사이드바)가 나타납니다. 관리자 전용 메뉴 (데이터 등록, AI 예측, IDW 보간)는 admin으로 로그인했을 때만 보입니다. 사이드바 맨 아래 로그아웃 버튼으로 로그아웃합니다.

서버를 켠 직후 바로 로그인하면 간혹 실패할 수 있습니다(계정 생성이 1초쯤 늦게 끝남). 잠시 후 다시 시도하세요.

6화면: 대시보드

대시보드 — 로그인하면 처음 보이는 화면으로, 현재 대기 상태를 한눈에 보여줍니다.

  • 상단 카드 5개 — 평균 PM2.5와 등급, 관측소 수, 최근 24시간의 관측·예측·보간 건수
  • 시간별 평균 PM2.5 (최근 24시간) — 전체 관측소 평균의 시간대별 변화 그래프
  • 관측값 vs AI 예측값 — 최근 AI 예측 결과와 그 시각의 실제 관측값 비교 그래프. 아직 예측을 실행한 적이 없으면 비어 있습니다. (10장 AI 예측 참고)
  • 공공 대기질·기상 카드 5개 — AirKorea 실측 대기질, 기상청 기상(기온·습도·바람·강수), PM2.5 예보(오늘/내일/모레), AI 추정 vs 실측 평균 오차, 공공 데이터 연동 상태. 자세한 내용은 15장 공공 대기질 참고

7화면: 3D 지도와 시계열 재생

3D 지도 — 관측소 위치와 PM2.5 값을 3차원 지구본 위에 표시합니다.

기본 조작 (마우스)

동작방법
지도 이동왼쪽 버튼 드래그
확대/축소마우스 휠
시점 회전(기울이기)가운데 버튼(휠) 드래그 또는 Ctrl + 드래그
상세 정보 보기마커나 격자 상자 클릭 → 팝업으로 PM2.5·등급·시각·좌표 표시

화면 구성

  • 마커(점) — 관측소 위치. 색으로 종류를 구분합니다: 관측 AI 예측 보간
  • 3D 격자 상자 — 관측소 상공에 떠 있는 반투명 상자들. 색이 PM2.5 등급을 나타냅니다.
  • 레이어 체크박스 (상단) — 관측/예측/보간/공공 대기질 레이어를 켜고 끕니다. 예측·보간 레이어는 해당 실행 이력이 있어야 표시됩니다.
  • 공공 대기질 레이어 — AirKorea 측정소를 하늘색 마커 + 농도 막대(원기둥)로 표시합니다. 상단 공공 기준항목에서 PM2.5/PM10/통합지수를 선택하면 막대 색(등급)과 높이가 바뀝니다. 막대 높이는 농도를 비교하기 위한 시각적 표현이며 실제 오염층의 높이가 아닙니다. 데이터가 없는 측정소는 회색 △로 표시됩니다(통신장애·점검 등, 오류 아님). 지도에는 지역 중심에 바람 화살표(기상청, 바람이 흘러가는 방향)도 표시됩니다.
  • 실측 IDW 표면 — 체크박스로 켜면 AirKorea 실측 다수 지점을 IDW로 보간한 색상 농도 면이 격자 형태로 표시됩니다(높이가 아닌 색으로 등급을 표현). 기본값은 꺼짐이며, 시/도 단위로 계산됩니다.
  • 시도 선택 — 상단 시도 드롭다운에서 전국 17개 시/도를 선택하면 공공 대기질 측정소·IDW 표면이 해당 시도로 바뀌고 카메라가 그 지역으로 이동합니다.
  • 경보 권역 — 현재 대기오염 경보가 발령된 시/도를 반투명 원으로 강조합니다 (경보=빨강, 주의보=주황). 경보는 시군구가 아니라 시도/예보권역 단위로 발령되므로 시도 단위로 표시합니다. 발령 중인 경보가 없으면 표시되지 않습니다. 경보가 없는 날 시연이 필요하면 15장의 "Mock 데이터로 시연하기"를 참고하세요.
  • 관측소 이동 — 관측소 선택 시 해당 위치로 카메라가 날아갑니다.
  • 핵심 대상지 버튼 — 인천 선택 시 상단에 미추홀구·남동구·연수구 버튼이 표시되며, 누르면 해당 구 상공으로 바로 이동합니다. 이 3개 구는 프로젝트의 핵심 대상지입니다.
  • 듀얼맵 — 버튼을 켜면 화면이 좌우로 나뉘어 왼쪽은 관측·공공 데이터, 오른쪽은 AI 예측·보간 데이터를 나란히 보여 줍니다. 오른쪽 지도는 왼쪽의 카메라와 시간을 자동으로 따라가므로 같은 지역·같은 시각을 바로 비교할 수 있습니다. 현재값 모드에서는 최신 예측·보간을, [시계열 로드] 후에는 선택 기간의 예측·보간 이력을 왼쪽 타임라인과 함께 재생합니다(예측·보간을 실행한 이력이 기간 안에 있어야 표시됩니다).
  • 거리 측정 — 버튼을 켠 뒤 지도를 좌클릭하면 지점이 추가되고 노란 선과 누적 거리(km)가 표시됩니다. 우클릭으로 측정을 끝내고, [측정 지우기]로 결과를 지웁니다.
  • 화면 캡처 — 현재 지도 화면을 capture_날짜_시각.png 파일로 저장합니다.
  • 배경지도 전환 — .env에 VITE_CESIUM_ION_TOKEN이 설정된 경우 [위성 지도]/[일반 지도] 버튼으로 배경을 전환할 수 있습니다 (토큰 없으면 버튼 미표시, OSM 고정).
  • 전체화면 — 지도 오른쪽 아래 전체화면 버튼을 누르면 지도만 화면 전체로 커집니다. ESC 키 또는 같은 버튼으로 원래 크기로 돌아옵니다.
지도를 처음 열면 핵심 대상지인 인천 미추홀구·남동구·연수구가 한눈에 보이는 화면으로 시작합니다. 이 지역에는 자체 관측소 6곳(미추홀주안·미추홀용현·남동구월·남동논현·연수동춘·연수송도)이 있으며, 다른 지역은 상단 시도 드롭다운으로 이동하세요.

시계열 재생 (시간에 따른 변화 보기)

  1. 지도 상단의 시계열 재생 영역에서 시작·종료 시각을 선택합니다. (처음 열면 데이터가 있는 마지막 24시간이 자동으로 채워져 있습니다)
  2. [시계열 로드] 버튼을 누릅니다. 잠시 후 재생 모드로 전환됩니다. 자체 관측소와 함께, 선택한 시도의 공공 측정소 실측도 누적된 값이 있으면 같이 재생됩니다.
  3. 화면 왼쪽 아래 원형 위젯에서 재생 ▶ / 일시정지 ⏸ / 배속을 조절합니다. 재생하면 시간이 흐르면서 격자·공공 막대의 색과 수치 라벨이 바뀝니다. (기본 배속: 1초당 15분)
  4. 화면 하단 타임라인 바를 클릭·드래그하면 원하는 시각으로 바로 이동합니다.
  5. [현재값 보기] 버튼을 누르면 다시 최신값 모드로 돌아옵니다.
데이터가 없는 시간대에는 해당 관측소의 격자가 화면에서 사라집니다(오류가 아닙니다). 공공 측정소 시계열은 서버가 매시간 수집·누적한 만큼만 재생되므로, 누적 기간이 짧으면 재생 프레임이 적을 수 있습니다.

8화면: 관측 데이터

관측 데이터 — 저장된 모든 관측값을 표로 조회합니다.

  • 상단의 관측소 선택으로 특정 관측소만 필터링할 수 있습니다.
  • 표 아래 이전/다음 버튼으로 페이지를 이동합니다.
  • 관리자로 로그인한 경우 각 행의 삭제 버튼으로 관측값을 지울 수 있습니다. 관리자

9화면: 데이터 등록 관리자

데이터 등록 — 새 관측소와 관측값을 직접 입력합니다. * 표시는 필수 항목입니다.

관측소 등록 (왼쪽 폼)

  1. 이름*, 위도*(-90~90), 경도*(-180~180)를 입력합니다. 예: 서울시청 → 37.5665, 126.9780
  2. 고도(m)·유형(SENSOR/STATION)·설명은 선택 입력입니다.
  3. [관측소 등록]을 누르면 즉시 목록과 3D 지도에 반영됩니다.

관측값 등록 (오른쪽 폼)

  1. 관측소*를 선택하고 관측 시각*을 지정합니다.
  2. PM2.5, PM10, 기온, 습도, 풍속, 풍향을 아는 만큼 입력합니다.
  3. [관측값 등록]을 누릅니다. 같은 관측소·같은 시각에 중복 등록은 안 됩니다.
CSV 파일 일괄 업로드는 실측 데이터가 확보된 후 제공될 예정입니다. 현재는 개별 등록만 지원합니다.

10화면: AI 예측 관리자

AI 예측 — 대기 사진과 환경데이터를 AI 모델에 넣어 PM2.5를 예측합니다.

예측하려면 학습된 모델이 먼저 있어야 합니다. "모델을 찾을 수 없습니다" 오류가 나오면 13장의 모델 학습을 먼저 수행하세요.
  1. 관측소*를 선택합니다. (예측 결과가 이 관측소 위치에 저장됩니다)
  2. 대기 이미지* — 하늘·대기가 찍힌 사진 파일(JPG/PNG)을 선택합니다. 샘플 이미지는 data/sample/dataset/images/ 폴더에 있습니다.
  3. 기온(℃)*, 습도(%)*, 풍속(m/s)*을 입력합니다.
  4. [예측 실행]을 누르고 몇 초 기다립니다.
  5. 오른쪽 예측 결과 카드에 예측 PM2.5·등급이 표시되고, 같은 시점의 실제 관측값이 있으면 함께 표시되어 비교할 수 있습니다.

실행한 예측은 아래 최근 예측 표에 쌓이며, 대시보드의 "관측값 vs AI 예측값" 그래프와 3D 지도의 예측 레이어에도 반영됩니다.

11화면: IDW 보간 관리자

IDW 보간 — 관측소가 없는 임의 지점의 PM2.5를, 주변 관측소의 최신 관측값으로부터 거리가 가까울수록 큰 가중치를 주어 추정합니다.

  1. 거리 가중치 지수 p를 정합니다 (0.1~10, 기본 2). p가 클수록 가까운 관측소의 영향이 커집니다. 잘 모르면 2를 그대로 두세요.
  2. 보간 방법을 선택합니다: 일반 IDW(기본) 또는 Modified IDW. Modified IDW는 최종보고서의 알고리즘으로, 관측소별 1차 보간 오차가 큰 지점의 가중치를 보정해 2차 보간합니다. 이력의 "알고리즘" 열에서 어느 방법으로 계산했는지 확인할 수 있습니다.
  3. 대상 지점의 위도·경도를 입력합니다(이름은 선택). [+ 지점 추가]로 여러 지점을 한 번에 계산할 수 있습니다.
  4. [보간 실행]을 누르면 지점별 추정 PM2.5와 등급이 표시됩니다.

실행 결과는 아래 이력에 저장되며, 3D 지도의 보간 레이어(보라색)에도 표시됩니다.

기존 관측소와 똑같은 좌표를 입력하면 추정값이 아니라 그 관측소의 실제 관측값이 그대로 나옵니다. 정상 동작입니다.

12화면: 모델 성능

모델 성능 — 현재 AI 모델이 테스트 데이터에서 얼마나 정확한지 보여줍니다.

  • 회귀 성능 — 예측 수치가 실제와 얼마나 가까운지: MAE(평균 절대 오차)·RMSE·MAPE·R². MAE가 낮을수록 좋습니다.
  • 등급 분류 성능 — 4등급(좋음/보통/나쁨/매우나쁨)을 맞춘 비율(정확도)과 혼동행렬(실제 등급 대비 예측 등급 분포).
현재 표시되는 수치는 합성(가짜) 샘플 데이터로 학습·평가한 파이프라인 검증용입니다. 실제 대기 사진 데이터의 성능이 아니므로 그대로 인용하면 안 됩니다. (화면에도 경고 배너로 표시됨)

13샘플 데이터와 AI 모델 준비

실측 데이터가 없어도 시스템 전체를 체험할 수 있도록 합성 데이터 생성기와 학습 스크립트가 포함되어 있습니다. AI 예측을 처음 사용하기 전 한 번 실행해 두세요.

# PowerShell, 프로젝트 루트에서
cd ai-service

# 1) 합성 대기 이미지 120장 + 정답 라벨(labels.csv) 생성
.venv\Scripts\python scripts\generate_sample_dataset.py

# 2) 샘플 모델 학습 (CPU로 약 2분)
.venv\Scripts\python scripts\train_model.py --epochs 5
  • 생성된 이미지: data/sample/dataset/images/ — AI 예측 화면에서 업로드 파일로 사용 가능
  • 학습된 모델: data/models/resnet18_multimodal_v1/ — 예측·모델 성능 화면이 자동으로 사용
  • 관측소 7곳 + 7일치 시간별 관측값은 DB 최초 생성 시 자동 입력됩니다.
.venv 폴더가 없다는 오류가 나오면 먼저 .\run.ps1을 한 번 실행하세요. 가상환경과 라이브러리가 자동으로 설치됩니다.

14자주 발생하는 문제

증상원인과 해결 방법
run.ps1 실행 시 "스크립트를 실행할 수 없으므로" 오류 PowerShell 실행 정책 때문입니다. powershell -ExecutionPolicy Bypass -File .\run.ps1로 실행하세요.
백엔드가 켜지지 않음: "type geometry does not exist" DB에 PostGIS 확장이 없습니다. DB 관리자 권한으로 CREATE EXTENSION postgis;를 실행하세요.
백엔드가 켜지지 않음: DB 연결 오류 .env의 접속 정보 오타, 또는 방화벽 문제입니다. Test-NetConnection <주소> -Port <포트>로 연결을 확인하세요.
서버 켠 직후 로그인이 실패함 기본 계정 생성이 서버 준비보다 약 1초 늦습니다. 잠시 후 다시 시도하세요.
AI 예측 시 "AI 서비스에 연결할 수 없습니다" (502) AI 서비스가 꺼져 있습니다. .\run.ps1로 다시 실행하거나 AI 서비스 창이 살아 있는지 확인하세요.
AI 예측 시 "모델을 찾을 수 없습니다" (400) 모델이 아직 학습되지 않았습니다. 13장의 학습 스크립트를 실행하세요.
3D 지도가 회색이거나 지도가 안 보임 인터넷 연결을 확인하세요(지도 타일은 온라인에서 받아옵니다). Cesium ion 토큰이 없으면 OSM 지도로 자동 대체되며, 이는 정상입니다.
화면이 로그인 페이지로 자꾸 돌아감 로그인 토큰이 만료되었습니다(기본 24시간). 다시 로그인하면 됩니다.
대시보드 "최근 24시간" 차트가 비어 있음 샘플 관측값이 DB 최초 생성 시점 기준이라 며칠 지나면 조회 창을 벗어납니다. backend에서 .\gradlew.bat bootRun --args='--airvision.sample.reseed=true'를 한 번 실행하면 현재 시각 기준 최근 7일 관측값을 삭제 없이 보충합니다(로그 확인 후 Ctrl+C로 종료, 이후 .\run.ps1로 정상 실행). 실측 데이터를 계속 입력하면 자연히 채워집니다.

더 자세한 운영·배포 정보는 docs/deployment.md를 참고하세요.

15화면: 공공 대기질 (예보·경보·AI 비교)

공공 대기질 — 환경부·한국환경공단 AirKorea와 기상청의 공공 데이터를 보여줍니다.

  • 대기질 예보 — 오늘/내일/모레의 권역별 등급(PM2.5·PM10·오존 선택 가능), 예보 개황·발생 원인·행동요령. 현재 측정값이 아닌 "예보"입니다.
  • 초미세먼지 주간예보 — 이후 4일의 권역별 낮음/높음 전망.
  • 대기오염 경보 — 올해 발령된 주의보·경보 이력. 발령 중인 경보가 있으면 모든 화면 상단에 빨간 배너가 나타납니다. 경보가 없을 때는 "발령 중인 경보가 없습니다"로 표시됩니다.
  • AI 추정 vs 공공 실측 — 우리 AI 모델의 최근 예측값과 가장 가까운 AirKorea 측정소 실측 PM2.5를 비교합니다(기본: 5km·60분 이내만 매칭). 절대오차·오차율·거리·시간차가 표시되며, 조건을 벗어나면 비교하지 않고 사유를 보여줍니다.

공공데이터포털 키 (선택)

  • 키가 없어도 내장 Mock 데이터로 모든 화면이 동작합니다. 이때 화면에 "Mock 데이터 (서비스키 미설정)" 배지가 표시됩니다.
  • 실제 데이터를 보려면 data.go.kr에서 활용신청 후 루트 .env의 AIRKOREA_SERVICE_KEY, KMA_SERVICE_KEY에 디코딩(원본) 키를 입력하고 백엔드를 재시작하면 자동으로 실 데이터로 전환됩니다. 자세한 절차: docs/public-data-api-integration.md
외부 API가 일시 장애일 때는 "마지막 정상 데이터를 표시합니다" 안내와 함께 직전 데이터를 계속 보여줍니다. 잠시 후 자동으로 복구됩니다.

Mock 데이터로 시연하기 (경보·예보 화면 확인용)

실제 키를 사용 중이면 대기오염 경보가 발령된 날에만 경보 배너와 3D 지도의 경보 권역 원이 보입니다. 경보가 없는 날에 이 화면들을 시연하려면, .env를 고치지 않고 백엔드만 잠시 Mock 모드로 켤 수 있습니다.

  1. .\run.ps1로 켜진 창 중 Backend 창만 닫습니다. (Frontend·AI 창은 그대로 둡니다)
  2. PowerShell에서 backend 폴더로 이동해 아래 한 줄을 실행합니다. 
    .\gradlew.bat bootRun --args='--airvision.public-data.mock-enabled=true --airvision.public-data.collection.enabled=false --airvision.public-data.collection.collect-on-startup=false'
  3. 브라우저를 새로고침하면 "Mock 데이터" 배지와 함께 인천 초미세먼지 주의보가 표시됩니다: 모든 화면 상단의 빨간 경보 배너, 3D 지도의 주황 경보 권역 원(+발령 라벨), 예보 카드(오늘/내일/모레)를 확인할 수 있습니다.
  4. 시연이 끝나면 이 창에서 Ctrl+C로 종료하고 .\run.ps1을 다시 실행하면 실제 데이터 모드로 돌아옵니다.
뒤의 두 옵션은 시간별 자동 수집을 끄는 것으로, Mock(가짜) 값이 실측 누적 테이블에 저장되는 것을 막아 줍니다. 그대로 붙여넣어 실행하세요.
