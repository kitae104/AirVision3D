# 관측 데이터·공공 대기질 화면 시각화 보강 설계 (Phase 36)

- 작성일: 2026-07-26
- 상태: 사용자 승인 완료(전체 범위 ①~④ 선택)

## 배경

두 화면 모두 표·텍스트 칩 위주라 필터링이 빈약하고 한눈에 상태가 읽히지 않는다는
사용자 피드백. 기존 API만 사용하고 백엔드는 변경하지 않는다.

## 관측 데이터 화면 (ObservationsPage)

- **필터**: 관측소 + 기간(시작일~종료일, API from/to Instant — 로컬 자정 기준 변환)
  + 초기화 버튼. 필터 변경 시 페이지 0으로.
- **요약 카드**: 필터 조건으로 최근 200건(size 상한이 200)을 별도 조회해
  전체 건수·평균 PM2.5·최고 PM2.5(시각·관측소)·등급 분포 비율 바(GRADES 색 구간) 표시.
  200건 초과 시 "요약·차트는 최근 200건 기준" 명시.
- **추이 차트**: 같은 표본을 시간 오름차순 라인 차트(recharts)로 표시.
- **표 개선**: PM2.5 셀에 등급색 미니 바(0~100㎍/㎥ 스케일) 병기.
- 순수 함수 `utils/obsStats.ts` `summarizeObservations`로 분리해 Vitest 테스트.

## 공공 대기질 화면 (PublicAirPage)

- **① 실시간 측정 현황 신설**(맨 위): GET /air-quality/current?sido= —
  시도 선택(SIDO_CENTERS) + 오염물질 선택(PM2.5/PM10/KHAI, publicGrades 기준).
  측정소별 농도 가로 바(등급색, 높은 값 순, 스크롤 영역) + 등급 분포 요약 칩 +
  측정 불가 측정소 수 + mock/stale 배지.
- **② 주간예보 매트릭스**: 텍스트 칩 나열 → 지역(행)×날짜(열) 색상 표
  (높음=주황, 낮음=파랑). 파서 `utils/weeklyMatrix.ts` `parseWeeklyMatrix`로 분리·테스트.
- **③ 경보 필터**: 항목(전체/미세먼지/초미세먼지/오존)·상태(전체/발령 중/해제됨)
  클라이언트 필터 + 발령 중 우선, 발령 시각 내림차순 정렬.
- **④ 악취 보강**: 관할 사업소 필터 + 희석배수 상위 10개 지점 가로 바 차트(등급색).

## 테스트

- Vitest: `summarizeObservations`(빈 목록·평균/최고·등급 분포), `parseWeeklyMatrix`
  (정상 파싱·형식 오류 무시·지역 순서 유지).
- tsc·vite build. 실기동: 백엔드 기동 후 두 화면 데이터 API 응답 확인
  (화면 육안 확인은 Chrome 확장 미연결로 사용자 몫).
