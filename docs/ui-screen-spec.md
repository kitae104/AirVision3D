# 화면설계서

프레임: 좌측 사이드바(메뉴·사용자 정보·로그아웃) + 콘텐츠 영역. 로그인 없으면 /login으로 리다이렉트.
관리자 전용 메뉴(데이터 등록/AI 예측/IDW 보간)는 USER에게 숨김 + 라우트 가드.

| # | 화면 | 경로 | 권한 | 주요 구성 |
|---|---|---|---|---|
| 1 | 로그인 | /login | 전체 | 아이디/비밀번호 폼, 오류 메시지, JWT 저장(localStorage) |
| 2 | 대시보드 | / | USER+ | 카드 5종(평균 PM2.5·등급 배지·관측소 수·24h 예측/보간 건수), 시간별 평균 차트, 관측vs예측 차트 |
| 3 | 3D 지도 | /map | USER+ | Cesium Viewer(OSM 폴백), 레이어 토글 3종, 관측소 flyTo, 등급 범례, 3x3x2 격자, 클릭 InfoBox, 시계열 패널(기간 선택→로드→재생/배속/Timeline) |
| 4 | 관측 데이터 | /observations | USER+ | 관측소 필터, 테이블(등급 배지), 페이지네이션, ADMIN 삭제 버튼 |
| 5 | 데이터 등록 | /data-entry | ADMIN | 관측소 등록 폼 + 관측값 등록 폼, 성공/오류 메시지 (CSV 업로드는 실측 데이터 확보 후) |
| 6 | AI 예측 | /predict | ADMIN | 관측소 선택·이미지 업로드·환경값 3종 → 결과 카드(예측값·등급·실측 비교) + 최근 예측 테이블 |
| 7 | IDW 보간 | /interpolation | ADMIN | p 입력, 동적 대상 목록(추가/삭제), 결과 카드, 최근 이력 테이블 |
| 8 | 모델 성능 | /metrics | USER+ | 회귀 지표 카드 4종 / 등급 정확도 + 혼동행렬(정답 초록·오분류 빨강), 합성 데이터 경고 배너 |
| 9 | 관리자 기능 | (통합) | ADMIN | 별도 화면 대신 5~7번 메뉴 + 목록 삭제 권한으로 제공 (MVP 결정) |

## 공통 UI 규칙

- 등급 배지/차트 색: `src/config/grades.ts` (좋음 파랑 / 보통 초록 / 나쁨 주황 / 매우나쁨 빨강)
- 모든 API 오류는 `errorMessage()`로 사용자 문구 표시 (네트워크 오류 포함)
- 로딩 상태 표시, 폼은 HTML 검증(required·min·max) + 서버 400 메시지 표시
- 401 수신 시 자동 로그아웃 후 /login 이동
